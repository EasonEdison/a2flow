# 定时任务编辑与关联运行

范围：B端定时管理，复用现有PATCH及运行详情。允许修改Cron、时区和执行输入；不改工作流，不自动启用任务，不重放已入队消息，不自动重试。

保存规则后按当前时间计算下一次未来触发，暂停状态保持。已入队StartWorkflow携带输入快照，不因后续编辑变化。下次时间按任务时区展示，停用时明确不会触发。

关联数据读scheduler_outbox内start_workflow及相同userId的run_ownership，不建立第二份运行状态表。SQLAlchemy只读投影返回具名DTO；userId、环境和任务归属校验。最近触发与历史分页读取；运行生命周期由Runtime查询，不从outbox completed推断成功。投递待确认/运行状态待确认不自动重试。

前端分出编辑器和历史组件，保留输入快照入口；最近结果与关联运行可跳现有RunDetail。并行状态请求最多4路，不在每张卡片单独扫描数据库。

验证：类型/构建/差异检查，真实隔离PostgreSQL用户隔离及历史关联，公网编辑停用任务后保存/刷新/历史跳转。不自动启动新的模型运行，不删除历史数据。
