## 最小验收标准

1. 管理页能查到真实资产及绑定；改变配置并重新发布后，新运行消费新配置，不改前端硬编码。
2. 三个 Skill 均可单独 Chat 使用，也可在 Workflow 顺序复用。
3. 三个节点都有真实交互；展示结束不冒充完成，失败确认不推进。
4. 最终稿件及输入来源从 DB 恢复；刷新页面不会丢失已保存成果。
5. 下载内容与用户选定的保存版本一致；输出不会自动发布到第三方。
6. 工具过程、业务产物、用户确认各有真实记录，没有第二套聊天记忆存储。
