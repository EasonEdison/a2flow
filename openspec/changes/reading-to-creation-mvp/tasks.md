## 阶段 2：真实资产与独立 Chat

- [ ] 盘点并补齐真正可渲染的组件，注册到组件中心。

## 阶段 3：三节点和公网验收

- [ ] M 端创建并发布顺序 Workflow，复用阶段 2 的原 Skill，不另写 Workflow 专用 Skill。
- [ ] 验证完整资料 → 观点确认 → 选题确认 → 编辑定稿 → 下载。
- [ ] 验证等待时刷新、重复点击、业务失败、未保存编辑和版本不一致。
- [ ] 两个账号验证素材、稿件、导出和 Action 隔离。
- [ ] 经批准部署到公网并浏览器实测；记录源代码 SHA、部署版本与运行证据。

## 最小验收标准

1. 管理页能查到真实资产及绑定；改变配置并重新发布后，新运行消费新配置，不改前端硬编码。
2. 三个 Skill 均可单独 Chat 使用，也可在 Workflow 顺序复用。
3. 三个节点都有真实交互；展示结束不冒充完成，失败确认不推进。
4. 最终稿件及输入来源从 DB 恢复；刷新页面不会丢失已保存成果。
5. 下载内容与用户选定的保存版本一致；输出不会自动发布到第三方。
6. 工具过程、业务产物、用户确认各有真实记录，没有第二套聊天记忆存储。
