# Output format

## Decision

One sentence describing the decision or question.

## Findings

For each material finding：

- **Supported** — directly backed by supplied material；name the source。
- **Inferred** — a bounded conclusion derived from supported findings；say why。
- **Unknown** — missing or conflicting evidence that matters。

## Next action

One concrete decision or bounded verification step。Do not add broad implementation work unless the caller requested it。
