# Personal workflows created in B chat

Approved scope, 2026-10-14. Management creates shared preset workflows. Employee users need a separate way to describe a requirement in chat and save a reusable workflow belonging to themselves.

The chat composer offers a quick action that fills an editable creation prompt without losing existing text. Ordinary natural-language requests also work. An Agent selects available published Skills and business capabilities, creates a validated personal workflow and returns a persistent result card. Successful creation immediately registers it under My workflows in the existing Workflow page; the same saved identity is shown in the original conversation. Creation alone does not execute business operations. Users explicitly run it through the existing execution flow.

Personal definitions are private by trusted owner and environment, not shared management assets with a different label. Their execution reuses the existing workflow engine, temporary missing-input interactions, automatic continuation after submission and factual summaries. No advance form configuration is required.

This first slice supports creation, owner listing/detail and execution. Editing, deletion, sharing, copying presets and new scheduling controls are outside scope. No new business backend, global management permission or automatic error fallback is introduced.
